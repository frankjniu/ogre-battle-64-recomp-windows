# HD backgrounds pack for Ogre Battle 64: Recomp.
#
# One line per background, whitespace separated:
#
#     <id>   <name>        <scene>  <step>
#
# id     names the image file in this folder: <id>.png (or <name>.png).
# name   a label for the background; it is printed in the port's log.
# scene  the scene id that draws the background, in hex (see docs/scenes.md).
# step   the scripted step number that selects it (`D_8018F1C0`).
#
# The port replaces the background image the game assembles for that (scene,
# step) pair with the PNG. See `docs/guides/hd-backgrounds.md`.
#
# A file named `<id>-wide.png` (or `<name>-wide.png`) beside the plain one is
# the widescreen variant: it is used when the WIDESCREEN setting is on. Author
# it in the widescreen aspect (16:9); the port scales it to the canvas width
# without stretching it, so circles stay round. It is optional: without it the
# plain image is used in both modes.
#
# Scene 0x0D is the dialogue/cutscene scene of the New Game opening. Step 2 is
# the cathedral (Archbishop Odiron). The opening's steps 1..19 are decoded in
# docs/HANDOFF-2026-09-15-session44.md.
#
# Scenes 0x04 (the title), 0x08 (the Hugo Report) and 0x12 (the Load Game
# book) take screen backdrops: the port draws the whole image behind the game's
# own logo, text, sprites, windows and book, 240 rows tall with its aspect kept
# and centred, so an image wider than 4:3 fills the widescreen sides. They have
# no step; the line carries `-`. title.png, loadgame.png, hugo.png and
# hugo-wide.png are AI-upscaled and outpainted from the game's own art, so they
# are not in the repository (see docs/guides/hd-backgrounds.md -> "Screen
# backdrops").
#
# Lines that start with '#' and blank lines are ignored.
#
# id  name       scene step
01    cathedral  0x0D  2
02    title      0x04  -
03    loadgame   0x12  -
04    hugo       0x08  -
